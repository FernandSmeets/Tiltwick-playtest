# Tiltwick TinyBuilder — temporary playtest

Browser test of the TinyBricks building editor. This repository contains the exported browser application only.

Open https://FernandSmeets.github.io/Tiltwick-playtest/ in Safari on your phone or in a desktop browser. Initial loading downloads approximately 52 MB before HTTP compression/cache.

Choose a part, tap a position and press Plaatsen. Use two fingers to pan and pinch to zoom. The bottom building library folds away after choosing a part.

Opslaan requests a JSON download. Keep that file on your device; Openen imports a JSON file. No server-side level storage, account system or analytics. Device/browser data is not a reliable backup. Physical iPhone testing is still required.

This is an unfinished test editor, not the finished game. The test site is public and downloadable. Search indexing is discouraged, not access-controlled. Publication may be disabled at any time; downloaded copies cannot be recalled.
